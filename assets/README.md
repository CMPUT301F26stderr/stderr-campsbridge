# Shared photography

`photos/{id}.jpg` and `photo-credits.json` are shared by Android and the HTML prototype. The catalog records each photographer, original photo page, download URL and license. Images are resized JPEG copies; screen containers may crop them for display. These are illustrative scenery photos, not photos of real listed campsites.

Android includes this directory in its main assets. Serve the repository root for the local prototype; Pages publishes these assets beside the storyboard. Update the catalog whenever a photo changes. The app's **Settings > Credits and licenses** and the prototype's **Photo credits** read this same catalog.
