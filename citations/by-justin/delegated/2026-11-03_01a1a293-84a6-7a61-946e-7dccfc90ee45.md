**The objective is broader than the spacing goal and can reward large detours for tiny gains.** In [space-corridors.py](/home/admin/Projects/campsbridge-storyboard-tooling/space-corridors.py:119), the sorted vector includes every inter-route segment pair, including distant, nonadjacent pairs. It rounds each clearance to 0.05 pt before comparison at lines 123–128. A move can therefore earn acceptance from an arbitrarily small change across a rounding boundary, while reducing raw clearances that remain in the same bins. The last 100 log entries include 38 one-bin gains; 8 moves shifted a lane by over 40 pt, and the largest shift was about 578 pt.

**This doesn’t permit an infinite cycle in the quantized objective.** Each accepted move strictly increases its sorted integer vector, and the bounded canvas gives that vector a finite state space. The practical number of states is still very large, so this is not a useful runtime guarantee.

Crossing pairs are assigned the same 1.1 value regardless of their actual separation or bridge geometry. That does not break termination, but it leaves crossing placement unscored beyond the bridge-feasibility check.

I recommend keeping full geometry and bridge checks as hard constraints, while scoring actual neighboring corridor pairs and relevant arrowhead-to-edge neighbors. Use raw clearances with an explicit improvement tolerance; use route movement or length only as a secondary tie-break.
